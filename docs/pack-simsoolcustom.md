# Overview

This is a guide to correctly installing and configuring the SimSool Custom Pack in Minecraft.

## Installation

1. Click the download button to download the `.zip` file.
2. Launch Minecraft, then go to **Options > Resource Packs > Open Pack Folder**.
3. Move the downloaded `.zip` file directly into that folder.
4. Activate **SimSool Custom Pack** from the in-game resource pack list.

## Do I need additional mods?

No. Additional mods are not required to use the CIT features. It functions perfectly using vanilla Minecraft features.
