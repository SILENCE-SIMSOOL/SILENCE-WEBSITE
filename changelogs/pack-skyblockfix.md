# Skyblock Fix Changelog

## 1.0.0 - 2026-07-09
- Initial release.

## 1.0.1 - 2026-07-09
- Added all Hypixel items and fixed an issue where Hypixel-exclusive icons were broken.

## 1.0.2 - 2026-07-30
- Added several SkyBlock items.

## 1.0.3 - 2026-08-05
- Added new items from the SkyBlock 0.27 update.

## 1.0.4 - 2026-08-26
- Added textures for newly added items in Hypixel.
- Added island-exclusive music.

## 1.0.5 - 2026-08-29
- Added several new items.
- Removed all music files. We determined that the music quality was not satisfactory, and we decided that keeping them removed by default is best so each individual can choose whether to enable music.

## 1.0.6 - 2026-10-07
- Adjusted structure to match changes from the SkyBlock 0.27.2 update.
- Applied textures for newly added items.

## 1.0.7 - 2026-10-31
### Bug Fixes
- Fixed an issue where textures for certain items (`Great Spook`, `cosmetics`, `statues`, `booster stones`, etc.) were missing and rendered incorrectly.
- Fixed a rendering issue where models for specific items such as `Golden Belt`, `Shen's Ringalia`, and `Critter Capsule` failed to load.

### Changes
- Updated item definitions to match the latest Hypixel SkyBlock resource pack.
