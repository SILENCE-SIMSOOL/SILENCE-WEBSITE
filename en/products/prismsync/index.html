PrismSync

Synchronize Prism Launcher
instances effortlessly.

PrismSync is a lightweight Windows application for managing Prism Launcher instances and easily synchronizing Minecraft settings and files between them.

Download for WindowsGitHub

Features

Manage your instances and apply your preferred environment across instances with minimal effort.

Instance Management

Automatically detects Prism Launcher instances and displays their configured icons.

Main Instance Selection

Choose your primary instance and switch between instances at any time.

Apply Settings

Copy selected settings and files from your main instance to another instance.

Customizable Synchronization

Choose which files and folders to synchronize in the Settings page.

Custom Config Presets

Save custom Minecraft (options.txt) and Sodium configurations to apply at any time.

Mod Auto-Update

Automatically checks and downloads the latest versions of SilenceUtils and LucentClient.

How It Works & Sync Rules

Synchronization always flows one way from your Main instance (A) to the Selected instance (B).

Step-by-Step Workflow

  1. 1
    Launch PrismSyncPrismSync automatically detects and loads your Prism Launcher instances.
  2. 2
    Select Main InstanceChoose your primary Minecraft instance as the synchronization source.
  3. 3
    Configure Sync OptionsOpen Settings and choose which files and folders to synchronize.
  4. 4
    Apply SettingsSelect another instance and click Apply settings.
  5. 5
    Review & CompleteReview the proposed changes in the preview window to complete synchronization.

Directories & Merge Behavior

Prism Launcher Directory%APPDATA%\PrismLauncher
PrismSync Configuration%APPDATA%\PrismSync
  • A-only files are created in B; B-only files remain untouched.
  • JSON and TOML configs are recursively merged so target-specific keys are preserved.
  • Identical files are skipped, and all CREATE, MERGE, and REPLACE actions are previewed before confirmation.
