01 / PHILOSOPHY

Design standards must be clear.

Keep decorations restrained so software functionality takes center stage, highlighting crucial information and actions.

01

Clarity

Establish information hierarchy first; visual elements serve solely to aid comprehension.

02

Consistency

Even across different screens, colors, spacing, and states must adhere to identical rules.

03

Restraint

Use violet accents and motion intentionally only to guide attention to key focus areas.

02 / IDENTITY

Quiet yet distinct presence.

The visual personality of SILENCE embodies composure, precision, and confidence. Below is the official SILENCE logo. Preserve original proportions and colors with transparent backgrounds.

SILENCE

Brand expression

Rely on generous white space, subtle violet accents, and articulate typography. Avoid aggressive neon hues, excessive gradients, and heavy drop shadows.

Never arbitrarily alter, re-color, or distort the proportions of the official logo.

06 / COMPONENTS

Crafted in small, consistent units.

Interactions with matching intent must retain the same anatomy. Primary buttons belong strictly to the single highest-priority action per view.

Component standards

Buttons/inputs min-height 44px, default radius 12px, cards 16px with 24px padding. All interactive elements must explicitly distinguish active, disabled, and focus states.

07 / INTERACTION

Fast, restrained feedback.

Design motion to clarify state changes rather than to display animation for its own sake.

01

Hover · 150ms

Focus on subtle background and border transitions.

02

Transition · 220ms

State and panel transitions remain calm and measured.

03

Motion · 320ms

Reserved strictly for essential content entrance.

Keyboard focus indicators must always remain visible; respect user reduced-motion preferences by dampening animations.

08 / ADAPTIVE

Restructure before scaling down.

On small viewports, collapse sidebars into drawers and collapse multi-column layouts into single flows. Preserve touch targets at 44×44px minimum.

10 / ACCESSIBILITY

Universal accessibility for everyone.

Designed targeting WCAG 2.2 AA conformance. Beyond contrast ratios, validate through actual keyboard traversal and screen reader audits.

Contrast

Aim for at least 4.5:1 for body copy; 3:1 for large display titles and primary non-text graphical boundaries.

Navigation

Ensure complete keyboard navigability; distinctively differentiate active view position from cursor focus.

Feedback

Never rely solely on color to convey status; accompany success and error indicators with plain semantic text.

Motion

Strictly honor operating system reduced-motion preferences.
