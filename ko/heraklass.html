HERA KLASS / JAVA BYTECODE

Java 코드 보호,
설정부터 빌드까지.

JAR를 열고, 보호 옵션과 적용 규칙을 정하고, 결과물을 빌드하세요. Hera Klass는 Java 바이트코드 보호 과정을 하나의 인터페이스로 연결합니다.

작업 흐름 살펴보기

THE WORKFLOW

프로젝트를 살펴보고,
보호 설정을 완성하세요.

02 / 08

프로젝트 상태를 한눈에.

클래스와 메서드 수, 의존성 상태, 활성화된 보호 옵션을 프로젝트 화면에서 확인하세요.

03 / 08

필요한 보호 기능을 선택하세요.

이름 변경, 문자열과 숫자 보호, 제어 흐름 등 각 변환의 설명을 읽고 개별적으로 켜거나 끌 수 있습니다.

04 / 08

세부 변환부터 네이티브 옵션까지.

참조, 호출 시그니처, 예외 흐름 보호와 디버그 정보 제거를 설정하세요. 네이티브 키와 메서드 보호 옵션도 같은 화면에서 관리합니다.

05 / 08

보호 수준을 직접 조정하세요.

Configure에서 기능별 세부 설정을 열어보세요. 문자열 보호는 Normal, Enhanced, Aggressive 수준의 차이를 확인하고 선택할 수 있습니다.

06 / 08

적용 범위도 명확하게.

기능별 포함·제외 규칙으로 변환할 클래스와 멤버를 지정하세요. 패키지 패턴을 사용할 수 있으며, 규칙이 겹치면 제외가 우선합니다.

07 / 08

의존 라이브러리를 함께 확인하세요.

자동 탐색으로 찾은 라이브러리를 확인하고, 필요한 JAR나 폴더를 직접 추가하세요. 다시 스캔해 의존성 목록을 갱신할 수 있습니다.

08 / 08

설정을 확인하고, 빌드하세요.

출력 경로와 보호 옵션 요약을 확인한 뒤 보호된 JAR를 빌드하세요. 클래스패스, 아카이브 처리 방식, 빌드 후 검증 항목도 함께 볼 수 있습니다.
