Lucent 개발자 가이드 및 API 레퍼런스

Lucent는 마인크래프트 Fabric 환경에서 현대적인 벡터 기반 GUI(NanoVG 및 Skija)를 구현하고, 복잡한 사용자 설정과 인게임 이벤트를 최소한의 보일러플레이트 코드로 처리할 수 있도록 설계된 차세대 모드 개발 프레임워크입니다.

1. 아키텍처 개요 및 설계 철학

전통적인 마인크래프트 GUI 개발은 OpenGL 고정 파이프라인(또는 구형 GlStateManager)을 수동 호출하여 픽셀 좌표를 직접 계산해야 했으며, 설정값 하나를 추가할 때마다 JSON 직렬화, GUI 슬라이더 바인딩, 이벤트 리스너를 파편화된 클래스에 분산 작성해야 했습니다.

Lucent는 이러한 문제를 해결하기 위해 다음의 3대 핵심 구조를 제공합니다:

1. 선언적 어노테이션 설정 엔진: 클래스 필드 위에 @ConfigProperty 등의 어노테이션을 선언하는 것만으로 자동 직렬화, 타입 유효성 검사 및 인게임 설정 GUI가 100% 자동 생성됩니다.
2. 단일 렌더 이벤트 파이프라인: NanoVG 벡터 컨텍스트를 마인크래프트 메인 렌더 버퍼에 바인딩하여, FPS 손실 없는 부드러운 안티에일리어싱(AA) UI와 벡터 폰트를 출력합니다.
3. 고성능 이벤트 버스: Java Reflection 오버헤드를 배제하고 바이트코드 런타임 생성(MethodHandle) 방식을 채택하여 일반 이벤트 루프 대비 4배 이상의 디스패치 성능을 발휘합니다.

2. 어노테이션 기반 설정 시스템 (코드 예제)

Lucent를 사용하면 단 몇 줄의 Java 코드로 모드의 설정 구조와 GUI를 완벽하게 정의할 수 있습니다.

설정 클래스 정의 예제

package net.silencehub.samplemod.config;

import net.silence.lucent.api.config.annotation.*;
import net.silence.lucent.api.config.type.ColorRGBA;

@Config(id = "sample_mod", name = "샘플 모드 설정", category = "HUD & Utility")
public class SampleModConfig {

	@ConfigProperty(
		name = "기능 활성화",
		description = "Silence 통합 HUD 렌더러를 활성화합니다.",
		order = 1
	)
	public static boolean enabled = true;

	@Slider(
		name = "HUD 투명도",
		description = "배경 패널의 불투명도를 설정합니다 (0.0 ~ 1.0).",
		min = 0.0f,
		max = 1.0f,
		step = 0.05f,
		order = 2
	)
	public static float hudOpacity = 0.85f;

	@ColorPicker(
		name = "텍스트 강조 색상",
		description = "상태 표시줄 및 주요 지표의 하이라이트 색상입니다.",
		allowAlpha = true,
		order = 3
	)
	public static ColorRGBA primaryColor = new ColorRGBA(30, 107, 255, 255);

	@Dropdown(
		name = "렌더 품질 모드",
		options = {"Fast", "Fancy", "Extreme Vector"},
		order = 4
	)
	public static String qualityPreset = "Fancy";
}

런타임 등록 및 직렬화 호출

import net.silence.lucent.api.LucentRegistry;

public class SampleModClient implements ClientModInitializer {
	@Override
	public void onInitializeClient() {
		// Lucent에 설정 클래스를 등록하면 AppData 디렉터리에 자동으로 저장 관리됩니다.
		LucentRegistry.registerConfig(SampleModConfig.class);
	}
}

3. 이벤트 시스템 구조도 및 디스패처

Lucent는 게임 내 주요 렌더 주기와 입력 신호를 정밀하게 가로채는 경량 이벤트 파이프라인을 운영합니다.
[ Minecraft Render Tick ]
           │
           ▼
[ Lucent Core Hook (Mixin) ]
           │
           ├─► EventStage.PRE_RENDER (월드 배경 및 버퍼 준비)
           │
           ├─► NanoVG Context Setup (스텐실 버퍼 및 벡터 캔버스)
           │          │
           │          ├─► Custom HUD Layouts (LucentClient)
           │          ├─► Registered Mod Widgets
           │          └─► Tooltip & Overlay Layer
           │
           ├─► EventStage.POST_RENDER (GL 블렌딩 모드 원상 복구)
           │
           ▼
[ Minecraft Framebuffer Swap ]

커스텀 렌더 리스너 구현

import net.silence.lucent.api.event.LucentRenderEvent;
import net.silence.lucent.api.graphics.NanoContext;

public class CustomWidgetRenderer {

	public static void onRender(LucentRenderEvent event) {
		NanoContext vg = event.getContext();

		// 부드러운 둥근 모서리 사각형과 네온 글로우 렌더링
		vg.beginPath();
		vg.roundedRect(100, 100, 240, 60, 12);
		vg.fillColor(SampleModConfig.primaryColor);
		vg.fill();

		// 고해상도 벡터 폰트 출력
		vg.fontSize(16.0f);
		vg.fontFace("Inter-Bold");
		vg.text(120, 135, "Silence Hub Connected");
	}
}

4. API 레퍼런스 요약

패키지 / 클래스메서드 / 어노테이션설명
net.silence.lucent.api.config@Config(id, name)설정 파일의 고유 식별자와 화면 표시명을 지정합니다.
net.silence.lucent.api.config@Slider(min, max, step)부동소수점 및 정수형 수치 범위 입력 슬라이더를 생성합니다.
net.silence.lucent.api.config@ColorPicker(allowAlpha)RGBA 컬러 팔레트 선택 모달을 바인딩합니다.
net.silence.lucent.api.graphicsNanoContext.roundedRect()GPU 하드웨어 가속 둥근 모서리 다각형을 그립니다.
net.silence.lucent.api.eventEventBus.subscribe()렌더 및 패킷 이벤트 콜백을 등록합니다.

5. 자주 묻는 질문 및 트러블슈팅

Q1: 모드 실행 시 UnsatisfiedLinkError (lwjgl_nanovg.dll)가 발생합니다.

해결법: 64비트 마인크래프트 네이티브 라이브러리가 누락되었거나 32비트 Java 런타임이 사용 중일 때 발생합니다. 64비트 최신 Java 21 이상 런타임을 사용하고 인스턴스를 재실행하세요.

Q2: 텍스트가 흐릿하게 렌더링되거나 깨져 보입니다.

해결법: 고DPI(High-DPI) 모니터 환경에서 마인크래프트 GUI 스케일과 물리적 픽셀 배율이 불일치할 때 발생합니다. SampleModConfig에서 'Vector Scaling Mode'를 Physical Pixel로 설정하면 레티나 디스플레이에서도 선명한 글씨를 얻을 수 있습니다.

Q3: Lucent와 LucentClient의 호환성 규칙은 어떻게 되나요?

해결법: LucentClient는 Lucent 코어 라이브러리를 내장(Shadow Bundle)하고 있으므로 일반 사용자는 LucentClient 단독으로 구동 가능합니다. 독립 모드 개발자는 빌드 시 compileOnly "net.silence:lucent:2.4.0"으로 의존성을 지정하세요.
