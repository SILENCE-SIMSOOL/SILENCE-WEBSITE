PrismSync

Prism Launcher 인스턴스 설정을
간편하게 동기화하세요.

PrismSync는 Prism Launcher의 여러 마인크래프트 인스턴스 간에 설정, 리소스팩, 셰이더, 월드 파일을 손쉽게 동기화할 수 있는 Windows 애플리케이션입니다.

Windows 다운로드GitHub

주요 기능

복잡한 과정 없이 메인 인스턴스의 환경을 다른 인스턴스로 그대로 가져올 수 있습니다.

인스턴스 자동 감지

Prism Launcher 인스턴스를 자동으로 감지하고 설정된 아이콘과 이름을 표시합니다.

메인 인스턴스 선택

기준이 될 메인 인스턴스를 지정하고 언제든지 다른 인스턴스로 전환할 수 있습니다.

원클릭 설정 적용

메인 인스턴스의 설정과 선택한 파일들을 대상 인스턴스로 간편하게 동기화합니다.

맞춤형 동기화 옵션

동기화할 파일 및 폴더 항목을 설정 페이지에서 원하는 대로 선택할 수 있습니다.

커스텀 프리셋 저장 · 적용

마인크래프트 옵션(options.txt)과 Sodium 설정을 별도로 저장해 두고 즉시 불러와 적용할 수 있습니다.

모드 자동 다운로드 · 업데이트

SilenceUtils와 LucentClient 모드의 최신 버전을 자동으로 확인하고 인스턴스에 다운로드합니다.

지원 동기화 항목

모든 동기화 항목은 앱 내 Settings 페이지에서 개별적으로 켜거나 끌 수 있습니다.

사용 방법 및 동기화 규칙

동기화 방향은 항상 메인 인스턴스(A)에서 선택한 대상 인스턴스(B)로 진행됩니다.

단계별 사용 흐름

  1. 1
    PrismSync 실행앱을 실행하면 Prism Launcher의 인스턴스 목록을 자동으로 불러옵니다.
  2. 2
    메인 인스턴스 선택설정의 기준이 될 메인 마인크래프트 인스턴스를 지정합니다.
  3. 3
    동기화 항목 설정Settings에서 동기화할 파일과 폴더 항목을 선택합니다.
  4. 4
    대상 인스턴스에 적용동기화할 다른 인스턴스를 선택하고 Apply settings를 클릭합니다.
  5. 5
    변경 내역 확인 및 완료프리뷰에서 생성·병합·교체될 파일 목록을 확인하고 동기화를 완료합니다.

기본 경로 및 병합 방식

Prism Launcher Directory%APPDATA%\PrismLauncher
PrismSync Configuration%APPDATA%\PrismSync
  • 메인(A)에만 있는 파일은 대상(B)에 생성되며, 대상(B)에만 있는 파일은 그대로 유지됩니다.
  • JSON·TOML 설정 파일은 키 단위로 재귀 병합하여 대상(B) 전용 설정 키가 지워지지 않도록 보존합니다.
  • 동일한 내용의 파일은 건너뛰며, 적용 전 프리뷰 창에서 생성·병합·교체 목록을 미리 확인할 수 있습니다.
