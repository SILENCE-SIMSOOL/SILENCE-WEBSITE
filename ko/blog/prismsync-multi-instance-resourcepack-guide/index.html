Prism Launcher 다중 인스턴스 관리 및 리소스팩·셰이더 동기화(PrismSync) 가이드

SILENCE
2026년 10월 21일

마인크래프트를 다채롭게 즐기는 유저들은 버전별(1.8.9 PvP, 1.20 모드팩, 1.21 바닐라), 서버별로 수많은 인스턴스를 생성해 운용합니다. 그러나 인스턴스가 늘어날 때마다 발생하는 가장 큰 문제는 스토리지 용량 고갈과 환경 설정 파편화입니다. 인스턴스마다 수 기가바이트에 달하는 동일한 리소스팩과 셰이더팩을 중복 복사하면서 SSD 용량이 낭비되고, 한쪽에서 바꾼 조작키가 다른 인스턴스에는 반영되지 않아 불편을 겪습니다.

본 가이드에서는 Windows 파일 시스템의 하드링크(Hardlink) 및 심볼릭 링크(Symlink) 기술을 응용한 PrismSync의 다중 인스턴스 동기화 아키텍처를 소개합니다.

1. 다중 인스턴스 스토리지 중복 구조와 심볼릭 링크

5개의 고해상도 리소스팩(각 2GB, 총 10GB)을 8개의 인스턴스에 복사하면 순수하게 텍스처 파일만으로 80GB의 용량이 소모됩니다.

[ 일반 복사 방식 ]
인스턴스 A (10GB) + 인스턴스 B (10GB) + 인스턴스 C (10GB) ... = 총 80GB 디스크 점유!

[ PrismSync NTFS 하드링크 / 심볼릭 링크 방식 ]
[ 중앙 마스터 저장소 (10GB) ]
       │
       ├──► 인스턴스 A (심볼릭 포인터: 0 바이트)
       ├──► 인스턴스 B (심볼릭 포인터: 0 바이트)
       └──► 인스턴스 C (심볼릭 포인터: 0 바이트)
==> 실제 디스크 점유량은 오직 10GB로 87.5% 절감!

Windows NTFS 파일 시스템은 동일 볼륨 내에서 하나의 물리적 데이터 블록을 여러 디렉터리 경로가 가리킬 수 있도록 지원합니다. PrismSync는 이 기능을 자동화하여, 마인크래프트 클라이언트가 파일을 로드할 때는 완벽한 로컬 파일로 인식하면서도 실제 디스크 공간은 중복 소비하지 않도록 보장합니다.

2. 설정 파일 파괴 없는 JSON/TOML 딥 머지 (Deep Merge)

단순히 options.txt나 config/ 폴더를 통째로 덮어쓰면, 특정 인스턴스 전용 모드 설정(예: 저사양 전용 렌더 거리, 고유 단축키)이 유실되는 대참사가 발생합니다.

PrismSync는 구조화된 설정 파일(JSON, TOML)을 트리 단위로 재귀 탐색합니다:

  1. 공통 키 동기화: 마스터 인스턴스에서 조정한 공통 그래픽 설정(FOV, 밝기, 사운드 볼륨)은 대상 인스턴스에 즉시 반영.
  2. 고유 키 보존: 대상 인스턴스에만 설치된 전용 모드의 설정 키는 그대로 유지.
  3. 충돌 방지 프리뷰: 동기화 실행 전 변경될 키 목록을 색상별로 사전 확인 가능.

3. 실전 사용 3단계 가이드

  1. 마스터 인스턴스 지정: PrismSync를 실행하고 본인이 가장 완벽하게 세팅해 둔 인스턴스를 클릭하여 마스터로 등록합니다.
  2. 동기화 항목 체크:
    • Resource Packs & Shader Packs: 하드링크 방식으로 즉시 연결.
    • Sodium Options: JSON 딥 머지 모드로 선택.
  3. 일괄 적용: 대상 인스턴스들을 다중 선택한 뒤 'Apply Sync'를 누르면 1초 내에 동기화가 완료됩니다.

정기 백업 스냅샷이 자동 생성되므로, 작업 도중 실수가 있더라도 원클릭으로 직전 상태로 복구할 수 있습니다. 자세한 프로그램 다운로드는 PrismSync 제품 페이지에서 확인하세요.
