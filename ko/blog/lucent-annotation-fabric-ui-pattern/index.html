어노테이션 기반 설정 라이브러리(Lucent)를 활용한 Fabric 모드 UI 설계 패턴

SILENCE
2026년 10월 22일

마인크래프트 Fabric 환경에서 사용자 인터페이스(GUI)를 개발할 때 가장 번거로운 작업은 수십 개의 옵션(토글, 슬라이더, 컬러 피커, 드롭다운)을 화면에 배치하고 이를 JSON 파일과 동기화하는 보일러플레이트(Boilerplate) 코드를 작성하는 일입니다.

Lucent 라이브러리는 선언적 어노테이션(Declarative Annotation)과 NanoVG 벡터 그래픽을 결합하여, 단 하나의 Java 클래스만으로 반응형 인게임 설정 UI와 직렬화 시스템을 자동 생성하는 현대적 아키텍처 패턴을 제시합니다.

1. 전통적인 모드 GUI 개발의 문제점

기존 바닐라 Screen 상속 방식은 다음과 같은 문제점을 안고 있습니다:

  1. 픽셀 좌표의 하드코딩: 해상도나 GUI 스케일이 변경될 때 레이아웃이 깨지기 쉽습니다.
  2. 동기화 파편화: 설정값을 변경할 때마다 인메모리 필드, GUI 상태, 디스크 파일 저장 로직을 개발자가 각각 따로 호출해야 합니다.
  3. 런타임 오버헤드: 리플렉션을 남용하는 라이브러리는 게임 시작 시 수백 밀리초의 클래스로딩 지연을 발생시킵니다.

2. Lucent의 선언적 UI 패턴 (Code Snippet)

Lucent에서는 단순한 정적 필드에 어노테이션을 부여하는 것만으로 완성도 높은 UI가 조립됩니다:

package net.silence.example.config;

import net.silence.lucent.api.config.annotation.*;
import net.silence.lucent.api.config.type.ColorRGBA;

@Config(id = "pvp_enhancer", name = "전투 오버레이 설정", category = "Combat")
public class PvPEnhancerConfig {

	@Category("시각 피드백")
	@ConfigProperty(name = "타격 플래시 활성화", description = "상대 피격 시 테두리에 붉은색 플래시를 출력합니다.")
	public static boolean hitFlash = true;

	@Slider(name = "플래시 지속시간(ms)", min = 50.0f, max = 500.0f, step = 10.0f)
	public static float flashDuration = 150.0f;

	@ColorPicker(name = "글로우 색상", allowAlpha = true)
	public static ColorRGBA glowColor = new ColorRGBA(255, 45, 85, 200);

	@Dropdown(name = "안티에일리어싱 모드", options = {"Fast", "Subpixel MSAA"})
	public static String aaMode = "Subpixel MSAA";
}

3. NanoVG 하드웨어 가속 렌더링 파이프라인

어노테이션으로 생성된 UI 요소는 NanoVG 벡터 엔진을 통해 GPU에서 안티에일리어싱된 고품질 다각형으로 렌더링됩니다:

import net.silence.lucent.api.event.LucentRenderEvent;
import net.silence.lucent.api.graphics.NanoContext;

public class CustomOverlayHandler {
	public static void renderHUD(LucentRenderEvent event) {
		NanoContext vg = event.getContext();

		// 부드러운 벡터 카드 렌더링
		vg.beginPath();
		vg.roundedRect(20, 20, 180, 50, 10);
		vg.fillColor(PvPEnhancerConfig.glowColor);
		vg.fill();

		// 벡터 텍스트 출력
		vg.fontSize(14.0f);
		vg.fontFace("Inter-Medium");
		vg.text(35, 48, "Status: Active");
	}
}

4. 아키텍처 도입 효과

  1. 코드량 80% 감축: 1,000줄 이상의 GUI 렌더링 및 파일 I/O 코드를 100줄 미만의 선언적 모델 클래스로 대체했습니다.
  2. 반응형 핫 리로드(Hot-Reload): 인게임에서 슬라이더를 드래그하는 순간 인메모리 필드와 파일 스토어가 실시간 동기화되어 게임 재시작이 필요 없습니다.
  3. 독창적 벡터 비주얼: 흐릿한 비트맵 폰트 대신 고해상도 모니터에서도 선명한 타이포그래피를 구현합니다.
