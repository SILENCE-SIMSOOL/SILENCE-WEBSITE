Astro 프레임워크 전면 전환을 통한 성능 대폭 개선 및 UI 정돈

웹사이트 아키텍처를 최신 Astro 프레임워크로 전면 전환하여 초기 페이지 로딩 속도와 전반적인 웹 퍼포먼스를 대폭 향상시켰으며, 사용자 중심의 탐색 구조와 인터페이스 디테일을 개선했습니다.

주요 업데이트 사항

  • Astro 프레임워크 전면 전환 및 성능 극대화: 웹사이트 엔진을 차세대 프레임워크인 Astro로 완전히 재구축했습니다. 불필요한 클라이언트 자바스크립트 오버헤드를 획기적으로 줄이고 정적 HTML 최적화를 적용하여 초기 로딩 속도와 페이지 전환 반응성을 비약적으로 끌어올렸습니다.
  • 사이트 내비게이션 및 탭 타이틀 개편: 브라우저 상단 탭에서 현재 위치를 명확히 파악할 수 있도록 탭 타이틀 표기 방식을 'Silence Hub (페이지명)' 형태로 일관성 있게 개편했습니다.
  • 메인 히어로 버튼 디테일 개선: 메인 화면 상단 액션 버튼에 직관적인 외부 링크 및 디스코드 아이콘을 적용하고, 모던한 라운딩 스타일을 반영하여 시각적 완성도를 높였습니다.
  • 메인 쇼케이스 영역 간소화: 쇼케이스 하단의 중복 액션 요소를 정리하여 핵심 기능과 콘텐츠에 더욱 집중할 수 있도록 화면 구성을 정돈했습니다.
  • 글로벌 폰트 및 가독성 최적화: 공식 영문/숫자 폰트 렌더링을 점검하고 시스템 전반의 텍스트 가독성과 일관성을 한층 강화했습니다.
  • 오픈소스 라이선스 페이지 정비: 누락되었던 라이선스 안내 페이지(/legal/license)를 정상 복구하여 법적 고지 및 오픈소스 정보 접근성을 확보했습니다.
2026-10-16

메인 쇼케이스 정돈 및 Venoux 상세 페이지 리뉴얼

공식 웹사이트의 메인 페이지 시각적 완성도를 높이고, Venoux 소개 페이지와 기여자 페이지를 정돈한 업데이트입니다.

주요 업데이트 사항

  • 메인 쇼케이스 레이아웃 최적화: Axion과 Hera 섹션에서 불필요하게 중복되던 정적 프리뷰 영역을 걷어내고, 주요 기능 캐러셀 루프 중심으로 화면 흐름을 일원화하여 한층 깔끔하고 직관적인 인터페이스를 구성했습니다.
  • Venoux 상세 페이지 리뉴얼: 공식 아웃트로 영상 프리뷰를 전면에 배치하고, 대시보드 텔레메트리 상세 뷰를 기능 1번에 연계했습니다. 복잡했던 박스 중첩 구조를 걷어내어 라이선스 안내 영역을 모던하고 정갈하게 개편했습니다.
  • Venoux 실사용 리뷰 섹션 도입: 실제 사용자 피드백을 기반으로 한 긍정 리뷰 갤러리를 신설하여 주요 활용 포인트(대시보드, 딥 클리너, 네트워크 설정 등)를 한눈에 볼 수 있도록 했습니다.
  • 기여자(Contributors) 페이지 업데이트: SILENCE 다국어 로컬라이징(영어 · 러시아어 번역 및 검수)에 기여해 주신 신규 기여자 정보를 공식 반영했습니다.

Venoux 인터페이스 프리뷰 및 메인 쇼케이스 전면 개편

SILENCE 메인 페이지의 Venoux 쇼케이스 및 사용자 인터페이스 경험을 대폭 개선한 업데이트입니다.

주요 업데이트 사항

  • Venoux 프리뷰 갤러리 개편: 최적화 앱 Venoux의 실시간 대시보드, 시스템 최적화, 딥 클리너, 네트워크 부스터, 서비스 관리자 등 주요 기능 화면을 직관적으로 확인할 수 있도록 인터페이스 갤러리를 전면 개편했습니다.
  • 부드러운 자동 기능 슬라이더 도입: 주요 기능을 3.5초 간격으로 자동으로 전환해 주는 스마트 슬라이더를 적용했습니다. 수동으로 버튼을 눌러 원하는 기능을 탐색할 수도 있습니다.
  • 미디어 전환 깜빡임 완벽 제거: 화면이나 영상이 바뀔 때 나타나던 검은색 깜빡임 현상을 완전히 제거하여 한층 매끄럽고 눈이 편안한 감상 경험을 제공합니다.
  • 메인 레이아웃 및 텍스트 정돈: 공식 인트로 비디오와 핵심 설명 문구의 배치를 정교하게 다듬고 제품 라인업 안내 영역을 한층 명확하게 다듬었습니다.

SILENCE 웹 서비스 성능 및 렌더링 최적화

SILENCE 웹 서비스의 전반적인 반응 속도 및 화면 렌더링 성능을 개선한 마이너 업데이트입니다.

주요 업데이트 사항

  • 배경 화면 렌더링 성능 최적화: 웹 페이지 스크롤 시 발생하던 불필요한 그래픽 연산 부하를 차단하여, 화면이 끊김 없이 한층 부드럽게 스크롤되도록 개선했습니다.
  • 이미지 애니메이션 개선: 메인 화면 이미지 쇼케이스 영역의 애니메이션 구동 방식을 효율화하여 저사양 기기에서도 매끄럽고 안정적인 움직임을 보이도록 최적화했습니다.
  • 프로젝트 상세 페이지 속도 향상: 제품 상세 페이지 내에서 탭을 전환하거나 다운로드 모달 등을 열 때 화면이 일시적으로 멈추는(렉) 병목 현상을 해결하여 한층 빠른 반응 속도를 제공합니다.
2026-06-23

SILENCE 웹 공식 릴리즈 및 UI/UX 성능 개선

SILENCE 웹 서비스의 첫 번째 공식 릴리즈 변경사항입니다.

주요 업데이트 사항

  • 실시간 다운로드 수 집계 시스템 통합: SilenceUtils, Lucent, Lucent Client 등 주요 오픈소스 프로덕트들의 누적 다운로드 수를 실시간 통계로 연동하여 보다 투명하고 상세한 정보를 제공합니다.
  • 다운로드 수 표기 가독성 개선: 100 단위 이상의 누적 다운로드 카운트를 영어 단위를 적용하여 소수점 둘째 자리까지(예: 1.47K) 깔끔하게 정돈했습니다.
  • 프로덕트 리스트 카드 디자인 개선: 카드 내부의 다운로드 수 표시 뱃지를 우측 상단으로 옮기고 디자인을 간소화하여 카드 컴포넌트의 가독성과 레이아웃 일관성을 향상했습니다.
  • 다양한 에셋 파일 타입 선택 지원: 깃허브 릴리즈 다운로드 모달에서 필요한 에셋 유형(Default, Lite, Library)이 존재할 경우, 유저가 원하는 빌드 타입을 선택할 수 있도록 옵션 선택 기능을 추가했습니다.
  • 네비게이션 헤더 UI 및 애니메이션 개선: 탑바의 카테고리 메뉴에 상태 지시 화살표를 도입하고 마우스 호버 시 180도 회전하는 부드러운 애니메이션을 적용했습니다. 메뉴가 열렸을 때 탑바의 배경색이 드롭다운 메가 메뉴 박스와 자연스럽게 일체화되도록 배경 불투명도를 조정했습니다.
  • 메뉴 포커싱 및 가독성 최적화: 메가 메뉴가 드롭다운되었을 때 탑바 하단의 배경 텍스트 콘텐츠들을 뿌옇게 블러(backdrop-blur) 처리하고 화면을 반투명하게 딤(Dim) 처리하여, 메뉴 내부 콘텐츠에 대한 시각적 집중도와 글자 가독성을 한층 더 강화했습니다.
  • 웹 속도 및 네트워크 요청 최적화: 웹 브라우저 새로고침이나 페이지 전환 시 빈번한 API 통신으로 인한 로딩 지연을 대폭 경감하는 네트워크 캐싱 파이프라인을 도입했습니다.
  • 실시간 설명 문서 렌더링 예외 처리: 외부 API 연결 지연 또는 만래 에러 발생 시 발생할 수 있는 문서 렌더링 깨짐 현상을 제어하는 안정성 핫픽스를 적용했습니다.
