PrismSync 다중 인스턴스 동기화 기술 가이드

PrismSync는 오픈소스 마인크래프트 런처인 Prism Launcher 사용자가 여러 버전(1.8.9, 1.20, 1.21 등)과 모드팩(Fabric, Forge, NeoForge) 인스턴스를 운영할 때 발생하는 설정 파편화 문제를 해결하는 전용 Windows 동기화 유틸리티입니다.

키 바인딩(options.txt), 그래픽 옵션(sodium-options.json), 수 기가바이트에 달하는 리소스팩과 셰이더팩을 인스턴스마다 중복 다운로드하거나 수동 복사할 필요 없이, 정교한 파일 시스템 제어 기술로 일관된 환경을 유지합니다.

1. 아키텍처 및 동기화 기술 원리

마인크래프트 인스턴스를 여러 개 복제하여 사용할 때 가장 큰 문제는 스토리지 낭비와 설정 불일치입니다. 2GB 용량의 고해상도 리소스팩 5개를 10개의 인스턴스에 복사하면 100GB의 디스크 용량이 낭비됩니다.

PrismSync는 다음과 같은 3가지 계층의 동기화 메커니즘을 지원합니다:

[ 기준 메인 인스턴스 (Source Instance) ]
                 │
                 ├─► 1. 대용량 파일 (리소스팩, 셰이더): NTFS 심볼릭 링크 / 정밀 복제
                 ├─► 2. 구조화 설정 (Sodium, Mod Config): JSON/TOML 재귀 키 병합 (Deep Merge)
                 └─► 3. 단순 텍스트 (options.txt): 키 매핑 보존 동기화
                 │
                 ▼
[ 대상 인스턴스 그룹 (Target Instances 01 ~ N) ]

A. 스마트 JSON/TOML 딥 머지 (Deep Merge)

단순한 파일 덮어쓰기(Overwrite)는 대상 인스턴스에만 존재하는 고유한 모드 설정(예: 특정 인스턴스 전용 렌더 거리, 고유 키 바인딩)을 날려버리는 부작용이 있습니다. PrismSync의 내장 직렬화 파서는 JSON 및 TOML 트리를 키 단위로 탐색하여:

  • 소스(A)에 새로 추가된 키는 대상(B)에 추가 주입.
  • 양쪽에 공통으로 존재하는 키는 소스(A)의 값으로 갱신.
  • 대상(B)에만 존재하는 특수 키는 그대로 보존하는 비파괴적 병합을 수행합니다.

B. 파일 해시 기반 무결성 검증 (xxHash64)

수천 개의 텍스처 파일을 비교할 때 파일 수정 시각(Timestamp)에만 의존하지 않고, 고속 xxHash64 알고리즘을 사용해 변경된 블록만 정확히 감지하여 디스크 I/O를 90% 이상 절감합니다.

3. 동기화 지원 데이터 매트릭스

사용자는 PrismSync의 '동기화 항목 설정' 탭에서 각 데이터의 동기화 여부를 세부 제어할 수 있습니다.

동기화 카테고리 대상 경로 / 파일 처리 방식 기본값
기본 조작 및 옵션 options.txt 주요 키 매핑 선택적 병합 활성
Sodium 그래픽 설정 config/sodium-options.json JSON 재귀 딥 머지 활성
리소스팩 라이브러리 resourcepacks/ 해시 대조 복제 / 링크 연결 활성
셰이더팩 컬렉션 shaderpacks/ 무결성 검사 후 배치 동기화 활성
모드 설정 폴더 config/*.json, *.toml 모드별 스키마 보존 병합 선택 활성
싱글플레이 세이브 saves/ 안전 백업 스냅샷 후 복제 비활성(보호)

4. 단계별 사용 워크플로우

1단계: Prism Launcher 자동 탐색

PrismSync를 실행하면 %APPDATA%/PrismLauncher/instances 또는 포터블 경로를 스캔하여 설치된 모든 인스턴스를 감지합니다. 커스텀 아이콘, 모드 로더 종류(Fabric/Forge), 마인크래프트 버전이 대시보드에 즉시 시각화됩니다.

2단계: 메인 소스 인스턴스 지정

자신이 가장 공들여 설정한 최적화 인스턴스(예: 1.21-Main-Fabric)를 클릭하여 'Set as Master Instance'로 지정합니다. 이 인스턴스가 모든 동기화의 기준점이 됩니다.

3단계: 동기화 항목 선택 및 프리뷰

대상 인스턴스를 체크한 뒤 'Preview Changes'를 누릅니다. 생성될 파일, 병합될 설정 키, 덮어쓰기될 항목이 명확한 색상(초록/파랑/주황)으로 표시되므로 실수로 인한 데이터 유실을 방지합니다.

4단계: 적용 및 롤백 지원

'Apply Sync' 버튼을 누르면 수 초 이내에 모든 인스턴스의 설정이 일괄 업데이트됩니다. 동기화 직전 이전 설정이 자동 백업 폴더(~/.prismsync/backups/)에 보관되므로 언제든 'Undo Last Sync'로 되돌릴 수 있습니다.

5. 트러블슈팅 FAQ

Q1: Prism Launcher가 설치되어 있는데 인스턴스를 찾지 못합니다.

해결법: Prism Launcher를 기본 경로가 아닌 다른 드라이브에 포터블(Portable) 형태로 설치했을 때 발생합니다. PrismSync 상단 메뉴의 'Settings -> Instance Root Path'를 클릭하여 instances 폴더가 위치한 경로를 직접 지정해 주세요.

Q2: 동기화 후 대상 인스턴스를 실행했는데 마인크래프트가 충돌합니다.

원인: 서로 다른 버전 간에 호환되지 않는 모드 설정 파일이 동기화된 경우입니다. (예: 1.8.9 Forge 인스턴스에 1.21 Fabric Sodium 설정을 주입한 경우)
해결법: 버전이나 로더가 완전히 다른 인스턴스 간에는 config/ 동기화를 끄고, resourcepacks/와 shaderpacks/만 선택적으로 동기화하세요.

Q3: 리소스팩 동기화 시 디스크 용량이 부족하다는 경고가 뜹니다.

해결법: 'Settings'에서 'Use NTFS Hardlinks / Symlinks' 옵션을 켜면 실제 디스크 용량을 2배로 쓰지 않고 하나의 원본 파일을 공유 참조하도록 구성할 수 있습니다. (동일 드라이브 파티션 내 지원)
