SILENCE / EXPERIENCE

Clarity in
every detail.

SILENCE만의 시각 언어를 정의하는 디자인 시스템. 모든 제품에서 명확하고 일관된 사용 경험을 제공하기 위한 기준이야. 이 자료들은 모두 자유롭게 열람하고 참고해도 돼.

Independent design system · Light & dark · Responsive

01 / PHILOSOPHY

디자인의 기준은 명확해야 해.

소프트웨어의 기능이 중심이 되도록 장식은 절제하고, 중요한 정보와 조작을 분명하게 드러내.

01

Clarity

정보의 위계를 먼저 정하고, 시각적 요소는 이해를 돕는 역할만 수행해.

02

Consistency

서로 다른 화면이라도 색상·간격·상태는 동일한 규칙을 따라야 해.

03

Restraint

보라색과 모션은 주목해야 할 위치를 안내할 때에만 적극적으로 사용해.

02 / IDENTITY

조용하지만 분명한 인상.

SILENCE의 시각적 성격은 차분함, 정확성, 자신감이야. 아래 이미지는 SILENCE의 공식 로고야. 원본 비율과 색상을 유지하고 투명 배경을 사용해.

SILENCE

Brand expression

여백이 넓은 화면, 은은한 보라색, 명료한 타이포그래피를 기본으로 사용해. 과한 네온, 무의미한 그라데이션과 높은 그림자 사용은 피해야 해.

공식 로고를 임의로 재구성하거나 색상 및 비율을 변경하지 마.

03 / TOKENS

Color system.

색상은 실제 HEX보다 역할을 먼저 정의해. 아래 카드를 누르면 HEX 값이 복사돼.

팔레트 미리보기는 페이지 테마와 별개야.
사용 원칙

04 / TYPOGRAPHY

Typography.

한글은 Pretendard, 영문은 Inter를 우선 선택하되, 기본 파일에는 외부 폰트를 포함하지 않아 설치되지 않은 기기에서는 시스템 글꼴을 사용해.

06 / COMPONENTS

작고 일관된 단위로.

같은 의미의 조작은 언제나 같은 형태를 사용해. 주요 버튼은 한 화면에서 우선순위가 가장 높은 동작에만 적용해.

Buttons

Primary · Secondary · Outline

Input

실제 사용 예시이며 입력 내용은 저장하지 않아.
컴포넌트 기준

버튼·입력창 최소 높이 44px, 기본 반경 12px, 카드 반경 16px, 내부 여백 24px. 모든 조작 요소는 활성·비활성·포커스 상태를 구분해.

07 / INTERACTION

반응은 빠르고 간결하게.

애니메이션 자체를 보여주기보다 사용자가 조작 결과를 이해하도록 설계해.

01

Hover · 150ms

배경색·테두리 변화를 중심으로 표현해.

02

Transition · 220ms

패널·상태 변경은 차분한 전환으로 표현해.

03

Motion · 320ms

콘텐츠 등장에만 제한적으로 사용해.

키보드 포커스는 항상 보여야 하며, reduced-motion을 사용하는 경우 불필요한 동작을 최소화해.

08 / ADAPTIVE

크기보다 구조를 먼저 바꿔.

작은 화면에서는 사이드바를 접고, 여러 열로 나뉜 콘텐츠를 한 열로 재배치해. 터치 영역은 최소 44×44px을 권장해.

Mobile≤ 767px

Desktop≥ 1024px

09 / ASSETS

필요한 그래픽은 목적에 맞게.

모든 에셋은 SILENCE 전용으로 제작하거나 명시적으로 사용 권한을 확보해. 공식 로고는 제공된 투명 PNG 파일을 사용하고, 인터페이스 일러스트는 별도로 제작한 SVG야.

10 / ACCESSIBILITY

모두가 사용할 수 있는 화면.

WCAG 2.2 AA를 목표로 설계해. 수치만 충족하는 것을 넘어 실제 키보드와 화면 읽기 환경에서 검증해야 해.

Contrast

일반 본문 4.5:1 이상, 큰 글자와 주요 비텍스트 시각 구분 3:1 이상을 목표로 해.

Navigation

키보드로 이동 가능해야 하고, 현재 위치와 포커스 위치를 구분해.

Feedback

색상에만 의미를 의존하지 말고 알림·오류에 명확한 텍스트를 함께 제공해.

Motion

사용자의 모션 감소 환경 설정을 존중해.
