Silence Hub 소프트웨어 설치 및 환경 설정 가이드

Silence Hub는 마인크래프트 Fabric/Forge 모드, Windows 시스템 최적화 데스크톱 도구, 모바일 주식 분석 애플리케이션 등 다양한 플랫폼에 걸쳐 고성능 소프트웨어를 제공합니다. 본 문서는 각 플랫폼별 설치 전제 조건, 단계별 가이드, 무결성 해시 검증 및 문제 해결법을 종합 안내합니다.

1. 플랫폼별 설치 전제 조건

소프트웨어 구동 전 아래의 하드웨어 및 런타임 환경이 갖추어져 있는지 확인하세요.

제품군 대상 플랫폼 필수 런타임 권장 사양
마인크래프트 모드
(SilenceUtils, Lucent, SilenceExtra)		 Windows, macOS, Linux Fabric Loader 0.16.0+
Java 21 (64-bit)		 Fabric API, Sodium 권장
시스템 유틸리티
(Venoux, PrismSync)		 Windows 10/11 (64-bit) .NET 8.0 Desktop Runtime 관리자 권한 (UAC)
금융 분석 도구
(Axion Desktop & Mobile)		 Windows 10/11 & Android Windows 64-bit / Android 9.0+ 안정적인 인터넷 연결
바이트코드 보호기
(Hera Klass)		 Windows, macOS, Linux Java 17 이상 런타임 4GB 이상 유휴 RAM

2. 마인크래프트 모드 설치 절차 (Fabric / Forge)

단계 1: 모드 로더 환경 구성

  1. Prism Launcher, Modrinth App 또는 마인크래프트 공식 런처를 엽니다.
  2. 새 인스턴스를 생성하고 사용할 마인크래프트 버전(예: 1.21.11 또는 1.8.9)과 모드 로더(Fabric 또는 Forge)를 선택합니다.
  3. Modern 버전의 경우 Fabric API 모드를 먼저 인스턴스의 mods 디렉터리에 넣습니다.

단계 2: 모드 바이너리 복사

  1. 공식 다운로드 센터에서 대상 .jar 파일(예: silence-utils-x.x.x.jar, LucentClient.jar)을 다운로드합니다.
  2. 운영체제별 마인크래프트 루트 디렉터리로 이동합니다:
    • Windows: Win + R 누른 후 %appdata%\.minecraft\mods 입력
    • macOS: ~/Library/Application Support/minecraft/mods
    • Linux: ~/.minecraft/mods
  3. 다운로드한 .jar 파일을 mods 폴더에 복사합니다.

단계 3: 실행 및 로딩 검증

게임을 실행하여 메인 타이틀 화면 좌측 하단에 모드 목록이 정상 출력되는지 확인하고, 게임 내에서 /silence 명령어를 입력해 설정 대시보드를 호출합니다.

3. Windows 데스크톱 애플리케이션 설치 절차 (Venoux, Axion, PrismSync)

  1. 설치 파일 다운로드: 제품 페이지에서 공식 디지털 서명된 실행 파일(.exe 또는 .msi)을 내려받습니다.
  2. 관리자 권한 실행:
    • Windows SmartScreen 알림이 발생할 경우 '추가 정보' -> '실행'을 클릭합니다.
    • UAC(사용자 계정 컨트롤) 창에서 '예'를 선택하여 시스템 드라이버 및 서비스 접근 권한을 승인합니다.
  3. 설치 경로 지정: 기본 경로(C:\Program Files\Silence Hub\)에 설치를 진행합니다.
  4. 초기 복원 지점 설정: Venoux와 같은 시스템 튜닝 도구는 최초 실행 시 시스템 복원 지점을 자동으로 생성하므로 잠시 기다립니다.

4. 파일 무결성 및 SHA-256 해시 검증

보안이 중요한 금융(Axion) 및 시스템(Venoux) 프로그램의 경우 공식 릴리즈 체크섬을 대조하여 변조 여부를 검증할 수 있습니다.

PowerShell을 통한 해시 검증

Get-FileHash -Path ".\Venoux-Setup-x64.exe" -Algorithm SHA256

출력된 해시 문자열이 릴리즈 페이지에 명시된 SHA-256 해시와 100% 일치하는지 확인 후 실행하세요.

5. 자주 묻는 설치 문제 해결 (FAQ)

Q1: 모드를 넣었는데 마인크래프트 실행 시 충돌(Crash)합니다.

원인: 다른 모드와의 Mixin 충돌이거나 자바 버전 불일치입니다.
해결: logs/latest.log 파일을 열어 어떤 모드가 원인인지 확인하고, 최신 Java 21 64비트 버전을 사용 중인지 점검하세요.

Q2: 윈도우 설치 프로그램 실행 시 '스마트스크린(SmartScreen)' 경고가 뜹니다.

원인: 신규 빌드 파일의 경우 마이크로소프트 클라우드 평판(Reputation) 데이터베이스가 동기화되기 전까지 경고가 표시될 수 있습니다.
해결: Silence Hub 공식 사이트에서 직접 다운로드한 파일인지 URL을 확인한 후 '추가 정보' -> '실행'을 눌러 진행하시면 안전합니다.

Q3: 이전 버전에서 업데이트하려면 어떻게 하나요?

해결: 기존 .jar 또는 프로그램을 삭제할 필요 없이, 새 버전을 덮어씌우거나 인스톨러를 재실행하면 이전 설정 파일(config/)을 그대로 보존하면서 바이너리만 자동 갱신됩니다.
