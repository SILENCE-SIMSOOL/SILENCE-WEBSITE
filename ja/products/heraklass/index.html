HERA KLASS / JAVA BYTECODE

Java protection,
from setup to build.

Open a JAR, choose protection options and rules, and build your output. Hera Klass brings the Java bytecode protection workflow into one interface.

Explore the workflow

THE WORKFLOW

Inspect your project.
Shape your protection.

02 / 08

Your project at a glance.

Review class and method counts, dependency status, and enabled protection options on the project screen.

03 / 08

Choose your protection.

Read the description of each transformation, from renaming to string, number, and control flow protection, and enable them individually.

04 / 08

Go further with protection options.

Configure reference, call signature, and exception flow protection, plus debug metadata removal. Manage native key and native method options in the same view.

05 / 08

Set the level of protection.

Open Configure to adjust a feature. For string protection, compare Normal, Enhanced, and Aggressive levels before choosing.

06 / 08

Define what gets transformed.

Use per-feature include and exclude rules to target classes and members. Package patterns are supported, and exclusions take precedence when rules overlap.

07 / 08

Keep dependencies in view.

Review automatically resolved libraries and add JARs or folders manually. Rescan to update the dependency list.

08 / 08

Review. Then build.

Review the output path and protection summary, then build the protected JAR. Classpath, archive handling, and post-build verification are listed alongside the configuration.
